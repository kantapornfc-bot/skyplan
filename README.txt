แผนฟ้า SkyPlan — วิธีติดตั้งบน Android

แอปนี้เป็น PWA (เว็บแอปที่ติดตั้งได้) ต้องอัปโหลดขึ้นเว็บที่เป็น https ก่อน แล้วค่อยติดตั้งจาก Chrome

วิธีที่ 1: GitHub Pages (ฟรี ใช้ได้ถาวร)
1. สมัครหรือเข้าสู่ระบบ github.com แล้วกด New repository ตั้งชื่อ เช่น skyplan (เลือก Public)
2. กด "uploading an existing file" แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้เข้าไป จากนั้นกด Commit
3. ไปที่ Settings > Pages > Branch เลือก main และ / (root) แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ https://<ชื่อผู้ใช้>.github.io/skyplan/

วิธีที่ 2: Netlify Drop
เปิด app.netlify.com/drop ในคอมพิวเตอร์ แล้วลากโฟลเดอร์ skyplan ทั้งโฟลเดอร์ลงไป

ติดตั้งบนมือถือ
เปิดลิงก์ใน Chrome บน Android แล้วกดเมนู ⋮ > "ติดตั้งแอป" (หรือ "เพิ่มลงในหน้าจอหลัก")
- อนุญาตตำแหน่ง กล้อง และเซนเซอร์ เมื่อแอปถาม
- หลังเปิดครั้งแรกแล้ว แอปใช้แบบออฟไลน์ได้ ยกเว้นแผนที่ (แผนที่บริเวณที่เคยเปิดไว้จะถูกเก็บไว้ดูออฟไลน์)

ถ้าต้องการไฟล์ APK จริง
นำลิงก์ไปใส่ที่ pwabuilder.com > Package for stores > Android จะได้ไฟล์ APK ไว้ติดตั้งหรือแจกนักเรียน

หมายเหตุความแม่นยำ
- ตำแหน่งดวงอาทิตย์ ดวงจันทร์ และทางช้างเผือกคำนวณด้วยสูตรดาราศาสตร์มาตรฐาน คลาดเคลื่อนราว 1 นาทีและน้อยกว่า 1 องศา
- จำนวนค่ำของข้างขึ้นข้างแรมเป็นค่าประมาณจากอายุดวงจันทร์ อาจไม่ตรงปฏิทินจันทรคติไทยทุกวัน
- โหมด AR ขึ้นกับเข็มทิศของมือถือ ถ้าเส้นไม่ตรงกับดวงอาทิตย์จริง ให้ใช้แถบ "ปรับเข็มทิศ" และ "มุมกล้อง" ช่วยปรับ
